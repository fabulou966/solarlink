# Product Backlog — SolarLink

Prioritized user stories (adapted from the SolarPMS practice doc).

| ID | User story | Priority | Points |
|----|------------|----------|--------|
| US1 | As an admin, I want to log in securely so only authorized users access data. | High | 3 |
| US2 | As a manager, I want to create/edit a project with size, budget and city. | High | 5 |
| US3 | As a manager, I want to upload and reorder photos with captions. | High | 5 |
| US4 | As a manager, I want to attach a BOQ PDF. | Medium | 3 |
| US5 | As a visitor, I want to request a quote. | High | 3 |

| US10 | As a manager, I want reports on projects. | Low | 5 |
| US11 | As a technician, I want to attach site photos. | Low | 3 |
